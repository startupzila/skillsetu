**Admin service** (`src/lib/admin/content-service.ts` — extended):

- `adminCreateBlock(input)` — create a block

**Lesson editor** (`src/components/learning/lesson-editor.tsx` — updated):

## Key Decisions

1. **Block editor uses live preview** — each block is rendered with ContentRenderer in the editor, so editors see exactly what learners will see.
2. **Block edit forms are per-type** — heading has level + text, callout has variant + title + text, code has language + code, etc. Complex types (table, related_content) show JSON for now.
3. **Reorder is simple up/down buttons** — not drag-and-drop (keeps it simple, works on mobile). Persists immediately via API.
4. **Question options use checkboxes** — for single_choice, selecting one deselects others. For multiple_choice, multiple can be selected.
5. **Block editor is lazy-loaded** — `next/dynamic` with loading spinner, so the lesson editor page stays fast.
6. **Editorial comments are resolvable** — can be toggled resolved/unresolved, useful for review discussions.
