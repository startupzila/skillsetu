## Goal

Build the structured content-block renderer (renders all MVP block types), the lesson page (with prev/next navigation + course sidebar), and the search page (PostgreSQL full-text search over courses/lessons/questions).

## What Was Built

### Content Block Renderer (`src/components/learning/`)

**`content-renderer.tsx`** — main component that maps each block type to its renderer.

**`blocks/index.tsx`** — individual block renderers for all MVP block types:

| Block Type | Renderer | Features |
|---|---|---|
| `heading` | HeadingBlock | Levels 1–6, dynamic tag, scroll-mt for anchors |
| `paragraph` | ParagraphBlock | Relaxed line-height |
| `image` | ImageBlock | src/alt/caption, lazy loading, figure/figcaption |
| `callout` | CalloutBlock | Variants: info, tip, warning, success, summary (each with icon + color) |
| `code` | CodeBlock | Language label header, monospace, overflow-x-auto |
| `table` | TableBlock | Headers + rows, responsive overflow |
| `quote` | QuoteBlock | Blockquote with left border, author attribution |
| `checklist` | ChecklistBlock | Checkbox-style items |
| `example` | ExampleBlock | Highlighted box with "EXAMPLE" label |
| `related_content` | RelatedContentBlock | Title + list of links |
| `quiz` | QuizBlock | Placeholder linking to quiz (full UI in S8) |
| `video` | VideoBlock | Feature-flagged placeholder (full video in S11) |

Unknown block types render a fallback with the type name.

### Lesson Page (`/courses/[slug]/[module]/[lesson]`)

- **`page.tsx`** — full lesson page with:
  - `generateMetadata` for SEO (title, description, OpenGraph)
  - **Breadcrumbs** (Home > Courses > Course > Module > Lesson)
  - Lesson header: duration badge, lesson_type badge, title, summary
  - Save/Notes buttons (wired in S8)
  - **ContentRenderer** — renders all content blocks from DB
  - **Prev/Next navigation** (within same module, computed server-side)
  - "Back to course" CTA when no next lesson
  - **Course Content sidebar** (desktop, sticky): full curriculum with current lesson highlighted
  - Responsive: sidebar hidden on mobile (`lg:block`)

### Search Service (`src/lib/content/search-service.ts`)

- `search(query, language, limit)` — full-text search across:
  - **Courses** (title, short_description)
  - **Lessons** (title, summary via lesson_translations)
  - **Questions** (question_text via question_translations)
- Uses PostgreSQL ILIKE for MVP (simple, no dedicated search tables)
- Returns `SearchResult[]` with type, slug, title, excerpt, URL, meta (difficulty, duration)
- Future: upgrade to tsvector or dedicated search engine when scale requires

### Search Page (`/search`)

- **`page.tsx`** — server-rendered search results:
  - Search form (autofocus, role="search")
  - Result count
  - Results list with type badges (Course/Lesson/Question), difficulty, duration
  - **EmptyState** when no results (with "Browse all courses" CTA)
  - **EmptyState** when no query ("Start typing to search")
  - SEO metadata

## Key Decisions

1. **Block renderer is a switch statement** — maps `block_type` to component; unknown types render fallback (graceful degradation).
2. **Block `data` is JSONB** — each block type has its own shape, validated at the service layer (Zod schemas to be added in S9 console editor).
3. **Lesson page is server-rendered** — for SEO and fast first paint.
4. **Course Content sidebar is sticky** — `sticky top-20` so it stays visible while scrolling the lesson.
5. **Search uses ILIKE for MVP** — simple, works without dedicated search tables. Will upgrade to tsvector or external engine when needed.
6. **Search results include type badges** — Course/Lesson/Question — so users know what they're clicking.
