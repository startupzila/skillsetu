## Goal

Build: affiliate link manager, ad slot manager, learner dashboard (continue learning, saved lessons, notes, quiz history, orders, downloads), and analytics (event tracking + admin metrics dashboard).

## What Was Built

### Marketing Service (`src/lib/admin/marketing-service.ts`)
**Affiliate links**: `adminListAffiliates`, `adminCreateAffiliate`, `adminDeleteAffiliate`, `adminToggleAffiliate`, `listActiveAffiliates` (public read)
**Ad slots**: `adminListAds`, `adminCreateAd`, `adminToggleAd`, `adminDeleteAd`, `listActiveAds` (public read)

### Analytics Service (`src/lib/analytics/analytics-service.ts`)
- `trackEvent(event)` — track product events (course_view, lesson_complete, etc.) via audit_logs table
- `getAdminMetrics()` — 14 aggregate metrics (learners, courses, lessons, questions, orders, revenue, enrollments, quiz attempts, bookmarks, notes, media assets)
- `getRecentEvents(limit)` — recent audit log entries

### Learner Dashboard (`/dashboard`)
- **Quick stats**: courses, quiz attempts, bookmarks, notes (4 stat cards)
- **Continue Learning**: enrolled courses with progress bars + "Continue" links
- **Saved Lessons**: bookmarked lessons with links
- **Recent Notes**: latest 5 notes with date
- **Recent Orders**: latest 5 orders with status + amount
- **Purchased Resources**: entitlements with download buttons
- Requires authentication (redirects to /login)

### Console Pages

**`/console/affiliates`** — affiliate manager:
- Create form (provider, product name, destination URL, disclosure)
- List with active/inactive toggle, delete
- Shows provider badge + disclosure text

**`/console/ads`** — ad slot manager:
- Create form (slot position selector: header/content_top/content_middle/content_bottom/sidebar/footer, name, code)
- List with toggle + delete, code preview

**`/console/analytics`** — analytics dashboard:
- 12 metric cards (learners, courses, lessons, questions, enrollments, quiz attempts, bookmarks, notes, orders, paid orders, revenue, media assets)
- Recent activity feed (audit log entries with action + timestamp)

### API Routes
- `GET/POST /api/admin/affiliates` + `POST/DELETE /api/admin/affiliates/[id]`
- `GET/POST /api/admin/ads` + `POST/DELETE /api/admin/ads/[id]`
- `POST /api/analytics/track` — track an event
- `GET /api/admin/analytics` — get metrics + recent events

### Console Sidebar
Added "Marketing" section (Affiliates, Ads) and "Analytics" under System.

### Seeded Data
- 1 affiliate link: Amazon — "Excel 2024 Complete Guide" (active)
- 1 ad slot: sidebar — "Demo Sidebar Ad" (inactive)
