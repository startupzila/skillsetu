## Key Decisions

1. **(public) route group** — shared Header + Footer layout for all public pages; console and auth have their own layouts.
2. **Server-rendered** — all public pages are server components for SEO; data fetched via Supabase JS client (RLS allows public read of published content).
3. **generateMetadata** — per-page SEO metadata from DB translations (title, description, OpenGraph).
4. **Breadcrumbs** — Home > Courses > [Category] > [Course], using the Breadcrumbs component from S5.
5. **Curriculum as links** — each lesson in the curriculum links to its lesson page (built in S7).
6. **Category filter chips** on /courses — links to /skills/[slug] (not client-side filtering, for SEO).
