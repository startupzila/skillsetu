## Key Decision: Data Access Architecture

The dev sandbox blocks raw TCP Postgres (port 5432) but allows HTTPS (port 443). So:
- **Runtime data access** = Supabase JS client over HTTPS — works everywhere (sandbox, preview, production)
- **Prisma** = schema source-of-truth only — `db:push` runs from a machine where port 5432 is reachable

Documented in `docs/architecture.md` §"Data Access" and `docs/deployment.md`.
