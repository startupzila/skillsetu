## Key Decisions

1. **SkillSetu** is a structured, multilingual, practical skills learning platform (not a blog/LMS template).
2. Core loop: Discover → Learn → Practice → Test → Apply → Track Progress.
3. Three surfaces: Public platform, Learner dashboard, `/console/` admin/editorial.
4. Content model: Category → Course → Module → Lesson → structured Content Blocks (lesson is never a hard-coded page).
5. Multilingual via translation entities (never `title_en`/`title_hi` columns).
6. Server-enforced RBAC + Supabase RLS.
7. Tech: Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui + Supabase + Prisma + Vercel.
