## Goal

Build the SkillSetu design system: design tokens (colors, typography, spacing), light/dark theme, global layout (header, sticky footer, breadcrumbs, language switcher, search box), responsive navigation, and base shared components (CourseCard, ProgressBar, StatusBadge, EmptyState, ErrorState).

## What Was Built

### Design Tokens (`src/app/globals.css`)
- **Brand color: teal/emerald** (growth, learning, professional) — NOT indigo or blue, per project rules.
- Full token system in light + dark mode:
  - Base: background, foreground, card, popover
  - Brand: primary, brand, brand-muted (teal-emerald)
  - Secondary, muted, accent
  - Semantic: destructive, **success**, **warning** (new)
  - Border, input, ring
  - Charts (5 colors)
  - Sidebar (full set)
- Accessibility:
  - `:focus-visible` with ring-2 + ring-offset
  - `prefers-reduced-motion` media query (disables animations)
  - Smooth font rendering, antialiased

### Theme System
- `src/components/providers/theme-provider.tsx` — wraps app in `next-themes`
- `src/components/public/theme-toggle.tsx` — Sun/Moon toggle button
- `attribute="class"`, `defaultTheme="system"`, `enableSystem`, `disableTransitionOnChange`
- Updated `layout.tsx` to include ThemeProvider

### Public Layout Components (`src/components/public/`)
| Component | Purpose |
|---|---|
| `Header` | Sticky header: logo, nav (Skills/Courses/Books/About), search, language switcher, theme toggle, auth buttons |
| `Footer` | Sticky-to-bottom footer: brand, link sections (Learn/Company/Legal), copyright |

|---|---|

## Key Decisions

1. **Teal-emerald brand** — distinct from indigo/blue (per rules), conveys growth/learning.
2. **Sticky header** (`sticky top-0 z-50`) with backdrop blur.
3. **Sticky footer** via `min-h-screen flex flex-col` + `mt-auto` on footer.
4. **Cookie-based language** (`skillsetu-lang`) — server components can read it for SSR.
5. **next-themes with `attribute="class"`** — works with Tailwind's `dark:` variant.
6. **Mobile nav uses shadcn Sheet** (side panel) — consistent with design system.
7. **CourseCard as a Link wrapper** — entire card is clickable.
