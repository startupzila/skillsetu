## What Was Built

### Testing Framework
- Installed **Vitest** + `@vitest/coverage-v8`
- Created `vitest.config.ts` with `@` path alias
- Added `bun run test` / `bun run test:watch` scripts
- **74 unit tests** across 3 test files, all passing:

**`tests/unit/utils.test.ts`** (28 tests):
- `slugify` — spaces, special chars, multiple hyphens, numbers
- `formatPrice` — INR, USD, zero, large amounts
- `calculateProgress` — percentage, zero total, cap at 100, negatives, rounding
- `computeDiscount` — fixed, percentage, max cap, exceeds total
- `isValidBlockType` — valid types, invalid, case sensitivity
- `canTransition` — draft→published, published→archived, archived→draft, invalid

**`tests/unit/auth.test.ts`** (23 tests):
- `PERMISSIONS` — 19 permissions, includes key ones
- `ROLES` — 11 roles, includes super_admin, media_manager
- `ALL_PERMISSIONS` — contains all 19
- `isStaff` — true for staff roles, false for null/empty
- `hasPermission` — super_admin wildcard, explicit permission, missing permission
- `validateCouponLogic` — active, inactive, expired, future-start, usage limit, min order

**`tests/unit/security.test.ts`** (23 tests):
- `sanitizeHtml` — escapes brackets, ampersands, quotes
- `validateFileUpload` — valid types, invalid type, size limit, empty MIME
- `validatePassword` — 8+ chars, short, empty, exact 8
- `validateRedirectStatus` — 301, 302, rejects 200/404/500
- `checkRate` — first request, up to max, after max, reset after window

### Course Templates (`src/lib/templates/course-templates.ts`)
4 configurable templates:
1. **Office Skills — Fundamentals** (beginner, 5h): 3 modules, 5 lessons, block outlines
2. **Digital Marketing — Basics** (intermediate, 4h): 3 modules, 5 lessons
3. **Software Tutorial — General** (beginner, 3h): 3 modules, 5 lessons
4. **Business Skills — General** (intermediate, 6h): 3 modules, 5 lessons

Each template includes: modules with lessons (title, summary, duration, block outlines), learning outcomes, prerequisites, target audience.

**Console page** (`/console/templates`): template grid with stats (modules, lessons, duration), module preview, outcomes, "Use this template" button.

### Content QA Checklist (`/console/qa`)
- **10-point quality standards** checklist (title, description, outcomes, prerequisites, audience, modules, lessons, blocks, EN published, thumbnail)
- **Per-course QA status**: shows each course with pass/fail badges for each check
- **Review scheduling**: shows last_reviewed_at, next_review_at, overdue indicator
- **Score**: X/9 checks passed per course
